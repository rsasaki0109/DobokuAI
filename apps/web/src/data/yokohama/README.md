# 横浜・みなとみらい — 公開都市モデルの表示用抜粋

原ファイルは以下の配信カタログ・アセットから取得しました。
[原カタログ](https://api.plateauview.mlit.go.jp/datacatalog/citygml/r:139.6314,35.4547?types=bldg)。
元の建物・地形・メタデータ、抜粋ファイルのbytes/SHA-256は `manifest.json` に記録しています。

`scripts/prepare-plateau-scene.py` で原モデルを加工し、指定矩形と交差する建物38件を
丸ごと選択、LOD1以外・テクスチャを除外しました。地形は全頂点が指定矩形内にある
原三角形を抽出しています。数値座標の変更・補間・平滑化はしていません。
表示用の抜粋で、完全な市街地・地形モデルではありません。地形の境界には欠けがあり得ます。
原の三角形を保存しており、抽出範囲の境界で切断して新しい三角形を作りません。

元メタデータは2024年度版がR5年度成果の製品仕様4.1への更新であること、
建築物LOD1は都市計画基本図、地形は航空写真測量成果から作成したことを記載しています。
全建物の現況・実測精度を独立に検証したものではありません。
水理解析用の水中河床断面、構造物設計用の実測形状として扱わないでください。
