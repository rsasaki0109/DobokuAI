# 将来の成熟度60%に向けた試行・照査パック

これは準備資料です。技術者レビューや現地河川検証の完了記録ではありません。
現在の合成例題だけで60%の必須条件を満たしたとは扱いません。
当面の目標は50%の社内評価版です。この資料のデータ・計算・成果・復旧の手順は
50%でも利用しますが、人によるレビューは将来60%の条件です。
50%の完了判定は [maturity goal](maturity-goal.md) に従います。

保存計算・感度・測点間隔比較の成果をまとめる[試行記録パック](review-pack.md)を実装しました。
同じ基本条件・基準高・版・基本結果の履歴だけを収録し、CSV/HTML/JSONを再計算せず出力します。
パック作成は、以下の実測データ・照査・復旧・レビュー等の完了を判定するものではありません。

## 必要な資料

1. 利用許可・出所を確認できる異なる河川/区間の測量データ3件。
   測量日、流下距離の意味、横断xの向き、単位、基準高、河床標高、粗度の根拠を記録。
   匿名化した案件データまたは利用条件が明示された公開データを使用。
2. 各ケースの対象流量・境界水深/水位・流況、断面遷移、堤岸、局所構造物の有無。
   対象外の物理現象がある場合は検証対象から外す理由を記録し、値を都合よく補正しない。
3. 外部の独立した解析手段/参照結果。モデル版、条件、座標/基準高、計算方法、
   α・Manning粗度・摩擦平均・局所損失の扱いを揃え、比較前に許容差を決める。
4. 独立照査できる技術者（目安2名、開発担当以外）の実際の操作レビュー。

外部の数値結果・現地観測・利用許可がないケースを作成済みと記載しません。
前段階ではHEC公式Webの取得制限と、試した公式GitHub例題パスが404だったことがありました。
その後、SWASHESの公開配布と埼玉県河床点群への資料を発見しました。
その後、[SWASHESの対応する常流/射流2例](swashes-validation.md)で外部参照照合を実施しました。
条件差の正規化・外部出力/計算の細分化・再生成照合を記録しています。
河床点群は配布元へのアクセス許可を追加しましたが、公開カタログがCloudFrontの403で
取得できず、利用条件・実ファイル・座標は未確認です。実河川試行や技術者レビューは完了していません。
公開データで進められる作業は [public-data roadmap](public-data-roadmap.md) に記録します。
利用者への連絡・募集は行っていません。

## ケースごとの試行

1. CSV形式へ明示的に変換し、元データと変換スクリプト/手順、両方のハッシュを保持。
   プレビューの行診断と断面図を確認。対応しない複断面や垂直区間を自動的に作り替えない。
2. 基準高・流量・境界流況/水深・粗度を照査。無施工の計算を実行して履歴を保存。
3. 施工案と感度条件を設定。適用範囲エラーも検証結果として残す。
   感度比較は専用履歴に保存され、失敗案の数値欄が空欄のCSVと図付きHTMLを出力できる。
4. 同一基準高で施工前後の図、水位差、掘削/盛土の符号、数量未算定の理由を確認。
5. 外部結果と測点別の水深/水位/流速を照合し、残差、誤差、測点細分化への感度を記録。
6. CSV/HTML/JSONを出力。別条件に編集しても旧履歴が元の結果/日時で開けることを確認。
7. SQLiteバックアップを作り、新規DBへ復元。保存した履歴・成果が一致することを確認。
8. AI提案の確認前は条件が変わらないこと、失敗操作で古い結果と条件の意味が混ざらないことを確認。
