# 河川の計算前診断

水理計算画面の「基本条件を診断」で、入力を変更せずに次を確認できます。

- 全断面の連続水面となる水深区間、限界水深を含む選択探索区間、限界・等流水深。
- 全隣接区間の河床勾配、幅比較に使った水深、上流/下流水面幅と幅比。
- 常流の下流端／射流の上流端に指定した水深、水位、Frと拒否理由。

基本条件だけを診断し、施工案や縦断水面形は計算しません。
各断面の根探索と遷移ガードは実際のRust計算と共通です。
断面の限界条件が不成立でも、他の断面と全遷移・境界の診断を返します。
入力の欠損・非有限値・粗度/流量の制限違反などは計算前に拒否します。
解が得られない項目は`null`で返し、画面では「—」と表示します。

**事前診断の通過は縦断計算の成立や精度の保証ではありません。**
縦断方向の水位追跡・収束・全測点での流況は、計算実行で別途確認します。
出典・利用条件・標高基準の正しさも、この数値診断では確認できません。

## 水深区間の読み方

幾何区間は河床からのmで、端点を除外します。
例えば`(0, 1) ∪ (2, 4)`なら水深1.5mやちょうど2mは分離流路となり対象外です。
選択探索区間は一意な最小エネルギーの限界水深を含む区間を数値余裕で狭めた範囲です。
上下限の小さな余裕も確認できるよう、画面では9桁の有効数字で表示します。
丸めた表示値を境界入力の推奨値として使わないでください。
[水深探索の手法・許容差](irregular-sections.md)を参照してください。

幅比は共通の参照水深での大きい幅／小さい幅で、1.25超を拒否します。
河床勾配は正が下り、絶対値0.1超を拒否します。判定は丸める前の数値を使用します。
これらは保守的な適用制限で、実河道の漸変性の証明ではありません。
実計算のエラーにも問題区間の流下距離を付記します。

## 保存・再現性

診断はプロジェクトや計算履歴DBを変更しません。
画面の「事前診断JSONを保存」から、入力River・診断値・エンジン版・UTC診断日時に加え、
プロジェクトID/名と標高・水平座標・取込み出典を持つ`reference`を出力できます。
入力や基準高などを変更すると前の診断値と保存ボタンを隠し、再診断を求めます。
診断JSONは計算履歴の復元ファイルではなく、再診断用の入力と当時の検査記録です。

API: `POST /api/diagnostics/river`、本文は[River型](../crates/doboku-core/src/lib.rs)そのもの。
応答の`can_attempt_profile`は事前検査に通過したことだけを表し、縦断解の成功フラグではありません。
APIのRiver入力はSI単位の局所座標です。単独のAPI応答にはプロジェクトの基準高・出典は含まれません。
Web画面の保存JSONは診断時のプロジェクト基準高・出典を付加します。
入力不正は422、診断内の成立しない条件は200応答の各`issues`に記録します。
例として`GET /api/sample`の`river`を送信できます。

検証は、計算と同じ限界/等流水深、境界方向、分離水面、複数区間の幅急変、欠損値、
APIでの無変更・履歴非保存、ブラウザでの入力変更後の無効化とJSON一致を対象とします。
