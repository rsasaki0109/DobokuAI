# 独立した水理照査ケース — 2026-10-11

既存の矩形常流の参照に加え、下記6ケースを標準逐次エンジンと独立に比較します。
参照計算はPythonの連続エネルギー式の微分方程式をRK4で積分します。
Rustライブラリ、標準逐次法の残差、Rustの断面計算関数は参照側で使っていません。
すべて合成条件で、実測校正やHEC-RAS等の外部製品との比較ではありません。

## 参照計算の式

```text
A = 湿潤断面積, P = 潤辺, T = 水面幅, R = A/P
Sf = (nQ / (A R^(2/3)))²
Fr² = Q² T / (g A³)
E = z + y + Q²/(2gA²), dE/dx = -Sf
dy/dx = (S0 - Sf + Q² A_x / (g A³)) / (1 - Fr²)
```

`A_x`は水深を固定したときの断面積の流下方向微分です。一定断面では0、
徐拡矩形では `.01*y` です。この項を無視した一定断面用の式で幅変化を照査していません。
局所損失や断面急変を扱う式ではなく、既存エンジンと共通の滑らかな1D条件を比較します。

矩形・台形は参照側で解析的な面積・潤辺・水面幅を評価します。
測量断面の面積は高さ方向の水平水面幅 `T(z)` を区分積分します。
Rust側の横方向の湿潤地形積分と異なる実装です。潤辺は各辺の浸水割合と辺長から求めます。
参照実装には、側方勾配の折れ点を含む断面について手積分で得た面積49.4m²、
水面幅17.8m（水深4m）などとの自己確認があります。

参照RK4は0.02mと0.01mの積分結果を比較し、各ケースの差は10⁻⁹m未満です。
今回の観測最大値は約8.2×10⁻¹⁴mでした。これを真の解との誤差保証や倍精度限界の
精度証明として扱いません。参照解の刻み幅依存が標準逐次法の比較誤差より小さいことの確認です。
