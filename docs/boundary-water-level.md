# 境界水位から水深を入力する

水理計算画面の「境界水位 (m / 共通基準高)」に、対象断面と同じ標高系の水位を入力できます。
現在の境界断面の河床標高を引き、既存の「境界水深 (m / 河床から)」へ反映します。
水深欄を編集すると、水位欄も河床標高＋水深に更新されます。

| 流況 | 境界断面 | 例（合成条件） |
|---|---|---|
| 常流 | 最下流の測点 | 河床9m・水位12.6m → 下流水深3.6m |
| 射流 | 最上流の測点 | 河床10m・水位10.55m → 上流水深0.55m |

欄の下に使用した境界測点の距離・河床標高・標高系を表示します。
入力はSIのmです。原測量がftなら、原資料で確認した単位で水位をmへ換算してから入力します。
横断CSVに指定した元単位を、水位欄へ自動適用しません。標高基準の変換や原水位の認証も行いません。

## 条件変更と保存

この欄は水深の別表現で、絶対水位を固定する新しい境界条件モードではありません。
保存する境界条件は従来の流況と水深です。河床標高・基準高はプロジェクトと計算履歴に記録します。
基本条件の河床や流況を変更すると、水深を保持して表示水位を再計算します。
測量CSVの反映後も、現在の水位と境界断面を再確認してください。
標高系の名前を編集しただけでは、河床や水位の標高基準を変換しません。

入力編集は作業中の条件を更新し、古い計算結果・AI提案の表示を解除します。
保存・計算履歴への追加は「プロジェクトを保存」「計算を実行」の明示的操作で行います。
保存結果を開くときは元の河床と水深で水位を表示し、再計算しません。

施工比較は既存のRustの計算を使い、境界水位を施工前と同じ高さに保持します。
例えば下流河床9m・水深3.6mで1m掘削すると、比較案の河床8m・水深4.6m・水位12.6mになります。
基本条件を手動で編集する場合と、施工比較中の境界の扱いを区別してください。

## 拒否と適用範囲

空欄・非有限値・河床以下の水位を正常な水深へ補正しません。診断を表示し、APIも計算を拒否します。
失敗した計算は水位結果や新しい履歴を作りません。
正の水深でも、越岸・限界流付近・指定流況との不一致・分離流路・縦断解の不存在等は、
従来の水理計算で拒否されます。水位の入力成功は、解の存在や実務適合の確認ではありません。

合成のブラウザテストで、両流況の境界位置、相互更新、基準高表示、保存・再表示、
1m掘削後の境界水位保持、河床以下/同高/空欄の拒否と元履歴の保持を検証します。
実河川の採用・現地校正は未完了です。[検証記録](validation.md)。
