# 断面削除の確認

横断面エディタの削除ボタンは、「断面削除の確認」を開きます。
削除対象の測点・距離・河床・粗度・地盤図と、削除後の断面数・境界条件を確認してから
「確認して断面を削除」で作業条件に反映します。保存と計算は別操作です。
取消や確認前の保存では、元の測点・条件を保持します。最低2断面を残します。

| 削除位置 | 影響 |
|---|---|
| 常流の最下流 | 新しい最下流を境界に使い、水深を保持。水位は新河床＋水深 |
| 射流の最上流 | 新しい最上流を境界に使い、水深を保持。水位は新河床＋水深 |
| 流況の境界ではない端点 | 既存の境界水位・水深を保持し、対象区間を短縮 |
| 中間の測点 | 前後の元測点を直接つなぐ。接続後の距離と間隔を表示 |

常流の合成例では、旧最下流河床9m・水深3.2mの水位12.2mが、
最下流を削除して新河床9.1mになると12.3mに変わります。
射流の合成例では、旧最上流河床10m・水深0.55mの水位10.55mが、
新河床9.8mになると10.35mに変わります。同じ基準高の境界条件の表示で、縦断計算結果ではありません。
以前の水位を固定したい場合は、削除後に同じ基準高の水位を水理計算画面で確認して設定してください。
入力値を補正したり、残った距離を0から振り直したりしません。

残る測点の座標・標高・粗度・形状と順序を保持し、補間・平滑化は行いません。
削除による測点間隔の増加・断面遷移の変化は計算に影響します。以前通過したガードや
刻み幅の照査は、削除後の条件で再確認してください。事前の確認画面は計算成立を保証しません。
流量・参照勾配・流況・水深・施工案を保持しますが、端点を削除すると工事区間・土量も変わり得ます。
中間点の削除でも地盤の起伏の表現が変わるため、施工比較は再計算してください。

測点の選び直しや元条件の編集では、古い削除候補を破棄します。
追加候補と削除候補は同時に開きません。確認後は隣接測点を選択し、全測点への形状反映をオフにします。
断面数が変わると未反映の測量点入力案を破棄し、再利用された番号へ古い入力案を転用しません。
元CSVの出典・ハッシュは元ファイルの記録を保持し、既存の保存計算履歴も変更しません。
削除後の条件・結果を記録するには、明示的に保存・計算を実行してください。

常流・射流それぞれの上流端・中間・下流端の合成6ケースと、測量点入力案/最低2断面のケースを検証します。
常流例の1m掘削では、端点削除で対象長が1,000mから900mとなり、土量が32,000m³から28,800m³へ変わります。
中間削除では同じ地盤の端点・長さを保持する合成条件のため、32,000m³を保持します。
これらはこの合成例の結果であり、任意の実測地盤で土量が同じになることを意味しません。
実河川データの採用・校正・適合の判定には数えません。
