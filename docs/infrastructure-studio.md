# 3D施設ギャラリー

架空の施設と周辺地形を、ブラウザのThree.js/React Three Fiberで表示します。
「3D施設ギャラリー」または起動したWebの `/?view=structures` で開けます。
ギャラリーは外部LLM・河川APIがなくても操作できます。

## 施設モデル

| 施設 | 作成した構成要素 |
|---|---|
| 重力式ダム | 台形状の堤体、コンクリート目地、洪水吐3系統、ゲート、巻上げ設備、管理橋、防護柵、取水塔、減勢工、管理棟、道路 |
| アーチダム | 湾曲する堤体、天端、放流設備、取水塔、貯水池、管理道路 |
| 斜張橋 | 2主塔、斜材、橋桁、橋脚、防護柵、舗装、路面表示、車両の作例 |
| 砂防堰堤 | スリット部、副堰堤、水叩き、側壁、渓流、礫 |

周辺の谷地形・森林、水面、コンクリートの質感をプログラムで生成しています。
外部の画像・測量データ・3Dモデルを利用していません。森林はインスタンス描画です。
斜張橋や砂防施設は表示用の固定作例です。寸法と配置の妥当性を検証した設計例ではありません。

## 操作と出力

- モデルを切り替え、全景・施設詳細・上流側・真上を選択。ドラッグで回転、スクロールで拡大。
- ダムでは堤高40〜100 m、表示上の貯水位30〜92%（堤高に対する比）、ゲート開度0〜100%を変更。
- 周辺地形/森林、水面、装飾アニメーションをオン/オフ。夕景と全画面を切り替え。
- 「モデルGLBを保存」で表示している形状を持ち出す。GLBには架空モデル・単位m・計算未連携の属性を保持。
- 「表示条件JSONを保存」で施設種別・形状値・表示設定を出力。JSONの読込み、表示条件の保存履歴は未実装。

設定はギャラリー内の一時状態です。河川プロジェクト、流量・粗度・断面、計算履歴には反映しません。
GLBは静的なモデル出力で、Three.jsの水面・放流アニメーションを含みません。
森林のGLB出力には `EXT_mesh_gpu_instancing` を使用します。読み込み側の対応が必要です。

## 数値計算との境界

施設、地形、放流は表示用の作例です。貯水池の水面は選択した高さと表示地形から生成する水平面です。
水面の質感と放流の演出は、流量・水圧・越流公式から計算していません。
ゲートや表示水位の変更による洪水調節・放流性能を評価する機能は未実装です。
別画面の [重力式ダムの予備照査](dam-calculations.md) では自由越流容量・剛体静力学を計算できます。
重力式ダムのカードからその画面を開けますが、ギャラリーの形状・水位・ゲート値を転送しません。
施設ギャラリーのモデル属性 `numerical_solver_linked:false` は引き続き正しい状態です。
応力・浸透場・耐震・アーチ作用・橋梁設計・砂防の土砂捕捉性能は未対応です。

検証済み河川計算は従来のRust 1D定常流エンジンで行います。
施設モデルを追加したことで、そのエンジンがダム・橋梁・砂防解析に対応したとは扱いません。
形状作例は実河川データの採用・設計認証・成熟度の加点根拠にも数えません。

## 確認したこと

- 全4種の幾何座標・法線・UVが有限値で、入力範囲外の表示パラメータを拒否。
- 貯水面が指定高さを保持し、ダム上流側の表示境界内に収まる。
- 河川APIを止めてもモデル切替・形状編集・視点・夕景・全画面が動作。
- ギャラリー操作による河川条件の変更・追加計算リクエストがない。
- GLB 2.0の出力、架空モデル/計算未連携の属性とインスタンス拡張、表示条件JSONの値を確認。

型チェック・Viteビルド、既存10項目を含む13項目を実行しました。
最終の施設3項目と配布用ビルドの3項目も確認しています。
物理性能の検証ではありません。[GIF撮影手順](readme-demos.md)。
