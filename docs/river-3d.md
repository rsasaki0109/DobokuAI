# 河床・水面の3D参考表示

縦断水面形の「3D 参考表示」をオンにすると、計算済み断面の地形と水面を立体表示します。
地形は面と表示用の切断面、水面は計算済み水位から生成した青い面です。
計算が未実行、または編集で結果が解除された場合は3Dも表示しません。

## 操作

- 「表示モデル」で施工前/計算済みの各案を切替。
- 「斜め」「俯瞰」「断面」で視点を変更。ドラッグで回転、スクロールで拡大。
- 「自動回転」をオン/オフ。「断面線」で元の横断形状を重ねて確認。
- 「3Dを全画面表示」で拡大し、「全画面を終了」で作業画面へ戻る。

カメラや表示モデルを変更しても、プロジェクト、計算条件、保存結果は変更しません。
数値計算APIへの追加リクエストも行いません。既定は静止画で、回転は利用者がオンにします。

## 座標・表示モデル

断面の横断xと共通標高、上流→下流の流下距離を使用します。
表示座標は横断x、基準河床からの標高差×3、区間中心からの流下距離×0.15です。
基準河床・区間中心・表示用底面とカメラの範囲は施工前後で共有します。
施工案を切り替えても、各案を独立に正規化しません。

流下距離は直線の表示軸です。平面上の実河川の曲がりやGIS地形を復元する機能はありません。
横断形状は矩形・台形・対応する測量断面の元の頂点を保持します。
隣接する断面を結ぶ際は断面折れ線の正規化した弧長に対応付け、両断面の頂点を残して面を張ります。
この補間は3D表示専用で、Rustの計算断面、測点間隔、数値結果へは反映しません。

河床の厚みを見せる側面・底面位置は表示用です。実測の地層や岩盤境界、
掘削数量を表すものではありません。地形の外縁は元断面の範囲を使用します。
水面は各測点の計算水位と断面の水際位置を結び、端部には水深を示す面を張ります。
1D定常解を静的な水面として描画し、カメラを動かします。3D流体解析は未対応です。
水位・水位差・土量の定量比較には2D図・計算結果・レポートを使用してください。

## 検証

`apps/web/tests/river-3d.spec.ts` で次を確認しています。

- 矩形から非対称測量断面への接続でも元の角と計算水位/水際位置を保持。
- 幾何座標と法線が有限値であり、入力条件・計算結果が変更されない。
- 施工前後の切替、3視点、自動回転、断面線、全画面がブラウザで操作可能。
- WebGLコンテキストが有効で、既存2Dグラフと数値条件を保持し、追加計算がない。

型チェック・Viteビルド、既存8項目を含む10項目のPlaywrightチェックを実行しました。
最終のカメラ・表示ラベルを含む3Dの2項目を再確認し、Vite previewの配布用ビルドでも2項目が成功しています。
READMEの3D GIFは実際のマウス操作とモデル切替を撮影しています。
[撮影手順](readme-demos.md)。紹介用の合成サンプルであり、実河川の検証件数には数えません。
