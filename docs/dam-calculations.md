# 重力式ダムの予備照査 — 実装仕様

対象は上流面鉛直・下流面直線の台形断面、堤軸方向1 mの剛体です。
静水圧、自重、基礎全幅の線形揚圧を決定論的なRustで評価します。
河川の標準逐次計算、施設ギャラリーの架空モデルとは独立した条件です。

実装順序: 水理の自由越流容量 → 構造の静力学 → 独立積分参照と解析解 →
API・保存スナップショット → ブラウザの条件編集・断面/荷重図・出力 → 検証。

## モデル・単位

- 高さ H、天端幅 c、底幅 B、水深 hu/hd: m。基礎面 z=0、上流端 x=0、下流端 x=B。
- 断面頂点: (0,0), (B,0), (c,H), (0,H)。0 < c ≤ B、0 ≤ hd ≤ hu ≤ H。
- コンクリート/水の単位体積重量 γc/γw: kN/m³。力は kN/m、モーメントは kN·m/m、接触圧は kPa。
- 自重は台形の面積・重心から算出。静水圧の水平成分は γw h²/2、高さ h/3。
- 下流斜面には水平成分と斜面勾配 s=(B−c)/H による鉛直下向き成分 s Pdを含める。
- 揚圧は上流端 γw hu → 下流端 γw hd の線形分布。排水効果・低減・粘着力は入れない。
- 滑動比は μN/(Pu−Pd)。水平差ゼロでは未定義(null)。転倒比は下流端まわりの抵抗/転倒モーメント。
- 合力位置と偏心から全幅線形接触圧を算出。合力が中央1/3を外れる場合は部分接触として圧を出さない。
  合力が基礎外、または有効鉛直力≤0なら、その状態と診断を返す。自動で安全/不安全の設計判定はしない。

## 自由越流

Q = C L (hu−zc)^(3/2)（hu > zc）、それ以外は0。
Lは有効越流幅(m)、zcは基礎面からの越流頂標高(m)、Cは有次元の係数(m^0.5/s)。
接近流速水頭を無視し、水位差を総水頭として使う簡易容量式。
係数は使用者が根拠に基づき指定する。ゲート開度による流量、潜り越流、流量からの貯水位逆算、
貯水池追跡、越流水の堤体荷重、シュート/減勢工の計算は対象外。
越流が発生し下流水位が越流頂以上になる場合は拒否する。
容量と静力学は別の理想化モデルであり、洪水吐部の構造設計を連成計算した結果ではない。

## 検証と制限

解析解（矩形、無水、両側同水位、揚圧過大）と、Pythonの数値積分による独立参照で比較する。
参照積分は台形を小矩形に分け、圧力分布を面積積分して力・モーメントを求める。
サンプルは合成条件で、係数や摩擦係数は例示値。実ダムの検証・設計基準適合を意味しない。

地震、動水圧、堆砂、温度、氷圧、浸透場、基礎変形、応力集中、材料強度、亀裂、3D/FEM、
アーチ作用、橋梁・砂防構造の照査は未実装。全幅接触を外れるケースで、
線形分布を無理に延長した負の接触圧を正しい結果として扱わない。

## 操作・成果・履歴

「ダム予備照査」または `/?view=dam` を開きます。APIキーは不要です。
合成サンプルを編集し、確認チェックを入れて「条件を確認して計算」を実行します。
寸法、材料重量、摩擦、上下流水深、越流頂、幅、有次元係数を明示して指定できます。
断面・荷重の方向、容量、滑動/転倒比、合力、適用可能な接触圧、診断を表示します。
条件編集は確認を解除し、現在の計算結果・成果出力を無効化します。

計算後に「基準に固定」で保存結果を固定し、変更条件を確認・再計算すると、
同じ局所座標・基礎面z=0・横縦同縮尺で断面と数値を比較できます。
下流斜面鉛直力も数値表に含めます。荷重図の下流水圧合力は斜面に垂直で下向き成分を持ちます。
荷重矢印の長さは力に比例しません。
接触圧図は全幅接触ケースだけを同じ座標と圧力軸で表示します。
基準との数値差は表示上の差分で、基準・変更各ケースの成果を個別に保存できます。

SQLiteの独立した`dam_runs`テーブルへサーバーが作った結果を追記します。
履歴は20件ずつ読み込み、元条件・結果・日時・エンジン版・モデル版を再計算せず復元します。
JSON・CSV・図入りHTMLには条件と診断を記録。未定義の比や対象外の圧はnull/空欄/「—」です。
クライアントが持ち込んだ数値結果を保存するAPIはありません。
既存DBは起動時に追加テーブルを得ます。河川条件・河川計算履歴は変更しません。
オンラインバックアップ/別パスへの復元CLIもダム履歴のJSON検査・件数記録に対応します。
条件JSONを任意に取り込むUI、比較差を一括出力するレポート、FEMは未実装です。

| API | 内容 |
|---|---|
| GET /api/dams/sample | 独立した合成条件 |
| POST /api/dams/runs | `{conditions:{name,dam,spillway},confirmed:true}` → `{id,run}` |
| GET /api/dams/runs?before=id | 履歴概要20件とnext_before |
| GET /api/dams/runs/id | 保存条件・数値・版・日時 |
| GET /api/dams/runs/id/reports/csv または html | 保存結果の成果、再計算なし |

サンプル: H=30 m、c=5 m、B=24 m、hu=27 m、hd=3 m、γc=24 kN/m³、
γw=9.80665 kN/m³、μ=0.7、越流頂25 m、有効幅20 m、C=1.7 m^0.5/s。
容量96.16652224137047 m³/s。サンプル係数は例示で、実施設の校正値ではありません。

構造の7独立積分ケースは [参照入力と結果](../examples/dam-reference.json) に固定し、
`python3 tests/dam_reference.py --check` とCargoテストで再検証します。
許容差は事前に1e−9×max(1,|参照値|)として、荷重・重心・モーメント・比・接触圧・状態を比較します。
独立計算は同じ静力学モデルの整合性を確認するもので、実ダム・規準適合の検証ではありません。
