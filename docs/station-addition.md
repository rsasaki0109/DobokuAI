# 下流断面の追加

横断面エディタの「下流に断面を追加」は、作業条件を変更せず追加候補を開きます。
距離の初期値は最下流＋100m、粗度・断面形状は最下流の複製です。
河床標高は空欄で、参照勾配から推定しません。確認した測量値または設計条件を入力してください。
複製した形状・粗度を新しい実測値として生成・認証したことにはなりません。

距離・標高・粗度を編集し、基準高・水平座標、複製元、地盤図、境界条件の影響を確認します。
標高・距離・粗度の有限値、最下流からの間隔0.1m以上、粗度0.005〜0.2を入力すると、
「確認して下流断面を追加」で1断面だけ反映できます。最大200断面です。
これらの簡易入力確認は、断面・勾配・流況などのRustによる最終検証の代わりではありません。
候補の地盤図には計算水面を表示しません。

| 条件 | 追加後 |
|---|---|
| 常流 | 新しい最下流を境界に使う。水深を保持し、水位は入力した新河床＋水深 |
| 射流 | 上流境界を保持。追加断面は下流側なので境界水位・水深を保持 |
| 既存測点 | 座標・河床・粗度を保持。全測点への形状反映をチェックしていても、追加操作は1断面だけ |
| 流量・参照勾配・施工案 | 保持。施工案を適用する区間の長さは延びるため、施工比較は再計算が必要 |
| 元CSVの取込み記録 | 元ファイルの記録を保持。追加・編集後の形状を元CSVが含むという意味ではない |

例えば合成の常流条件で、旧下流河床9m・境界水深3.2mなら旧水位12.2mです。
新下流河床8.9mを入力すると、保持した水深による新しい境界水位は12.1mになります。
旧水位を固定したい場合は、追加後に水理計算画面で同じ基準高の水位を確認して設定してください。
追加時に観測水位や測量標高を補正しません。表記の表示桁を丸めても、入力・保存値は丸めません。

取消では元の測点数・条件を保持します。元の作業条件を編集した場合も候補を破棄します。
確認前にプロジェクトを保存しても、候補は保存しません。
確認後は新しい測点を選択し、全測点への形状反映をオフにします。保存と計算は別操作です。
既存の保存計算は変更しません。新しい区間での計算を実行してください。
形状・粗度・標高の根拠や、追加区間の構造物・非定常流等の適用範囲は別途確認が必要です。

合成の常流・射流2ケースで、標高の必須入力、距離/粗度の不正入力、取消、候補の無効化、
確認前と保存前の無変更、既存全断面の完全一致、実際のRust縦断計算・境界水位・流況と
保存履歴の不変を検証します。実河川データの採用・現地校正とは数えません。
