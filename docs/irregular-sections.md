# 地盤の起伏を保持する横断計算 — エンジン0.2.0

横断測量の地盤点を並べ替え・平滑化・削除せず、起伏を持つ区分線形断面を扱います。
対象は**計算水面で連続した1流路となる条件**です。
複数流路への流量配分、横断方向の粗度分割・速度分布、跳水・非定常流は未対応です。

## 入力と計算の区別

測量点はxが厳密な昇順、相対高さz≥0、最低点z=0、両端は正の堤岸高。
断面ごとに3〜200点。垂直区間・重複x・非有限値・越岸を拒否します。
幾何の入力検証では、細かな凹凸があることだけを理由に拒否しません。
CSVプレビューの成功は、指定流量/境界で解が得られることや、標高基準の確認成功を意味しません。

実際の水深で水面下の区間を数え、1区間だけのとき面積・潤辺・水面幅を評価します。
地盤の峰をちょうど水面が通り、流路が接続点だけで分かれるケースも拒否します。
例: `(0,4),(1,0),(2,2),(3,1),(4,4)` は水深1.5mでは分離、水深3mでは接続。
水深3mの面積は127/24m²、水面幅は41/12mで、手積分と照合します。

## 水深範囲と解の探索

頂点の標高で区切った各水深区間について、連続1流路となる範囲を列挙します。
その全範囲で限界条件を探し、最小エネルギーに対応する限界水深が一意であることを要求します。
計算、境界水深、等流水深は、その限界水深と同じ連続水深範囲に限定します。
限界水深が存在しない、複数ある、段差の不連続を根として扱うことになる場合は拒否します。
一意な等流水深が得られない場合も診断付きで停止します。

水深区間内では面積Aは二次式、水面幅Tと潤辺Pは一次式になります。
頂点の両側に加え、次の導関数の符号変化から得た区間内の極値も探索点に含めます。
単純な粗い水深グリッドだけでは見逃す、横断方向の急な広がりによる複数根を検査します。

```text
限界条件: Fr² = Q² T/(g A³) = 1
Fr²の極値: T' A − 3T² = 0
Manning容量: Qn = sqrt(S0)/n × A^(5/3)/P^(2/3)
Qnの極値: 5TP − 2P'A = 0
```

測量断面の根は最大120回の二分探索で、水深区間幅10⁻⁹mに加え、
限界条件の残差|Fr²−1|≤10⁻⁸、容量残差|Qn−Q|≤10⁻⁸×max(Q,1)を満たすまで解きます。
非有限値、不連続や倍精度で解消できない残差はエラーです。
標準逐次計算のエネルギー残差≤10⁻⁷m、常流Fr<0.98／射流Fr>1.02の条件は維持します。

隣接幅比25%のガードは、両断面が連続1流路となる共通水深を使います。
従来の堤岸高の半分がその範囲内なら使い、範囲外なら最も近い共通区間の中点を使います。
共通区間がなければ拒否。これは検証用の保守的なガードで、実河道の遷移が緩やかなことの証明ではありません。

## 独立参照

検証断面は合成データで、実測校正ではありません。

```text
(-10,6), (-5,.6), (-3,0), (-1,.12), (1,.04), (3,.18), (5,.5), (9,6)
```

Rustとは別に、水平方向の交点を対にして高さ方向の湿潤幅を積分します。
峰より低い高さの水平切片は複数に分かれるため、幅を外側2点だけから求めず、各切片を合計します。
実水面は1区間であることを参照側でも確認。連続GVF式をRK4で積分します。
参照刻み0.02/0.01mの差は常流約2.9×10⁻¹⁴m、射流約9.5×10⁻¹²mでした。

| 条件 | 常流 | 射流 |
|---|---:|---:|
| Q m³/s / n / S0 | 15 / .035 / .001 | 15 / .025 / .02 |
| 延長 m / 境界水深 m | 400 / 下流3.6 | 100 / 上流.5 |
| 粗/細の測点間隔 m | 20 / 4 | 5 / 1 |
| 最大水深差・細 m | 約4.3×10⁻⁸ | 約4.3×10⁻⁵ |
| 改善倍率 | 約24 | 約26 |
| 事前許容差 m / 最低改善倍率 | 5×10⁻⁵ / 15 | 10⁻⁴ / 10 |

固定値: [reference-irregular.json](../examples/reference-irregular.json)。
再生成/検証: `python3 tests/irregular_reference.py [--check]`。
Cargoでは [共通の参照比較](../crates/doboku-hydraulics/tests/reference_cases.rs) と
[拒否条件・点列保持](../crates/doboku-hydraulics/tests/irregular.rs) を検証します。
刻みの改善や合成参照との一致を、実河川の精度保証に外挿しません。

## 成果と互換性

同じ常流ケースをCSVから試すには [river-irregular.csv](../examples/river-irregular.csv) を使用できます。
水理計算で流量15m³/s、参照勾配.001、下流境界水深3.6mを指定し、
横断面エディタで相対高さ・合成基準高・データ種別「合成」を指定してプレビュー・確認取込みします。
CSVは21断面、粗度.035、元の8地盤点を含みます。施工案は取込み時にクリアされます。
計算後、施工比較画面から掘削案を追加できます。これは実河川試行用データではありません。

計算仕様変更を識別するため、エンジン/アプリ版を0.2.0に更新しています。
保存JSONの型は維持し、過去の結果は再計算せず元の版・日時・値で取得します。
河川CSVは既存列の末尾に`warnings_json`を追加しました。
HTMLにも保存された計算時の注意を出力し、現在のモデルの説明で古い保存結果の注意を置き換えません。
CSVの列を固定数で読む利用者は追加列への対応が必要です。

CSVの取込み、計算、掘削比較、レポート、分離水面の拒否と履歴保持をブラウザで検証しました。
取得済み実データの基準高・原測量が未確認という状況は変わらず、採用0件と成熟度44.0/100を維持します。
