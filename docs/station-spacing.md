# 測点間隔による結果差

測点を細かくすると、同じ補間モデルの計算結果がどの程度変わるかを確認する補助機能です。
元の区間を2分割・4分割し、**元測点だけ**で水位・水深・流速を比較します。
元の条件は変更せず、施工案はこの比較に適用しません。
差が小さくても、現地の精度・収束・測量品質・境界条件の妥当性を保証しません。

## 補間の前提

- 河床標高と粗度を各区間内で線形補間。元測点は数値を変更せず保持します。
- 矩形同士は幅・堤岸高、台形同士は底幅・法勾配・堤岸高を線形補間します。
- 測量断面同士は点数・各点の横断x・相対高さ0の位置が一致するときだけ、各点の相対高さを補間します。位置の推定・点の再配置・平滑化は行いません。
- 異なる断面形式の間は未対応。元の断面と生成した断面の両方に通常の検証を適用します。
- 元の幅急変・河床勾配・流況制限は、分割しても回避できません。分割後も200断面以下・間隔0.1 m以上が必要です。
- 流量・参照勾配・境界水深・流況は固定。追加断面は仮定した形状であり、追加の測量ではありません。

Webの確認チェックを有効にしてから「基本条件を保持して測点間隔を比較」を実行します。
APIは `POST /api/resolution`、入力は `{project, confirmed_interpolation:true}`。
基本計算が失敗した場合は422です。基本計算が成功した後の各分割の失敗は理由付きで返し、
失敗した案のprofile・差・実行済み断面を捏造しません。計算同時実行は他の計算と共通で4件です。

## 表示と成果

各分割の「元の計算からの最大絶対水位差」と「直前の分割からの最大絶対水位差」を表示します。
直前の分割は2分割では元の計算、4分割では2分割。いずれも同じ元測点で評価します。
2分割が失敗した場合の4分割の直前差は未算定です。符号付き差はグラフ・JSON・CSVに残します。
自動的な精度合格判定、Richardson外挿、未測量形状の精度推定は行いません。

JSONには元プロジェクト・出典・補間後の全河川条件・全計算点の結果・失敗理由・エンジン版・比較日時を記録します。
CSVは元測点のみを出力し、基本計算の差は0、失敗案の数値と補間条件は空欄にします。
文字セルは引用符と表計算の数式対策を行い、符号付きの数値は数値として出力します。
出力時は表示結果を使い、再計算しません。条件編集時は結果と補間確認を解除します。
SQLite履歴、JSON再取込み、専用HTMLレポートは未実装です。

## 独立参照による検証

既存の独立した連続エネルギーODE/RK4参照の6ケースを、参照位置の元測点から2/4分割しました。
参照生成側はDobokuAIの補間・逐次計算を呼びません。各段階で誤差が前段階の1/2未満になる
という条件を検証しています。以下は元測点での最大水深誤差（m）です。

| ケース | 2分割 | 4分割 |
|---|---:|---:|
| 矩形・非一様射流 | 1.627674e-3 | 3.945694e-4 |
| 台形・非一様射流 | 5.194037e-4 | 1.285225e-4 |
| 台形・常流 | 3.157679e-6 | 7.878013e-7 |
| 非対称測量断面・常流 | 1.457714e-6 | 3.696115e-7 |
| 測量頂点を水面が横断 | 3.454227e-5 | 8.633485e-6 |
| 緩やかな矩形幅変化 | 6.262224e-5 | 1.565893e-5 |

これは特定の合成検証ケースの数値誤差です。4分割でも矩形射流の誤差は約0.0004 mであり、
「4分割で任意のケースが実務精度に達する」とは宣言しません。
実行方法: `cargo test -p doboku-hydraulics --test resolution -- --nocapture`。
参照の再生成は `python3 tests/reference_cases.py --check`。
補間の手計算値、元測点/境界の保持、点配置不一致、分割数・断面数・最小間隔・幅急変を検証します。
APIは確認・未知フィールド・基本条件の失敗・個別失敗・DB無変更を検証します。
ブラウザは確認前の実行禁止、比較、数値なしの失敗案、JSON/CSVの元日時と数値、条件編集時の解除を検証します。

合成サンプル青葉川では11→21→41断面になり、元の計算からの最大絶対水位差は
2分割で1.899687e-5 m、4分割で2.373870e-5 mでした。
2分割から4分割への差は4.741831e-6 mです。「元の計算からの差」と
「参照解に対する誤差」は別の量であり、元の計算からの差は細分化で大きくなることもあります。
