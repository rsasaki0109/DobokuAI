# 保存成果のオフライン照査

`scripts/audit-review-pack.py`は、[試行記録パック](review-pack.md)をPython標準ライブラリだけで
読み、ファイルの整合と保存JSONの水理収支を確認します。Python 3.11以上が必要です。
API・ブラウザ・LLMキーは不要です。
対象は`doboku-review-pack-1`と保存エンジン0.2.0です。

```bash
mkdir -p .local
python3 scripts/audit-review-pack.py --pack /path/to/saved-pack.zip --output .local/new-audit.json
python3 tests/test_review_audit.py
```

成功は終了コード0、失敗・未対応形式は2です。検査に失敗しても診断JSONを出力し、
既存レポートへの上書きは拒否します。ZIPをディスクへ展開しません。
許可した7〜13ファイルの名前、重複、CRC、最大65 MiBの展開サイズ、ファイル一覧、
各ファイルのサイズ/SHA-256と条件ファイルのハッシュを点検します。
選択ID・元のエンジン版/日時・案数/失敗数・プロジェクトと基本条件の一致も確認します。
失敗案は診断として残し、失敗JSONへの計算結果の混在を拒否します。

## 水理の確認方法

Rustエンジンを呼び出さず、保存された条件と水深からPythonで諸量を再算定します。
矩形・台形も有限堤岸を持つ地盤折れ線に置き換え、水面で各辺をクリップして
台形積分による流水面積A、潤辺P、水面幅Tを求めます。測量断面は全頂点を保持します。
越岸、分離した濡れ領域、非有限値、断面/計算行の不一致は照査失敗として記録します。

モデルの単位は保存RiverのSIです。元測量の単位や基準高を推定する処理ではありません。
水理半径R=A/P、V=Q/A、Sf=(nV/R^(2/3))²、Fr=V/√(gA/T)、
比エネルギーE=y+V²/(2g)を計算し、g=9.80665m/s²、α=1を使います。
各区間で上流/下流の河床差と比エネルギー差から、平均Sf×区間距離を差し引きます。
保存された`energy_residual`を信用して合格とせず、区間収支を別に求めます。
常流・射流の境界位置を区別し、指定境界水深と流況（Fr<0.98 / Fr>1.02）を照合します。
限界水深のFr=1、記録済み等流水深のSf=参照勾配も確認します。
等流水深が`null`の行は、未算定のまま件数を報告します。

| 確認対象 | 判定許容値 |
|---|---|
| 保存値と再算定値 | 絶対1×10⁻⁸または相対1×10⁻⁸。各諸量の保存SI単位 |
| 区間エネルギー収支 / 保存残差との差 | 絶対1×10⁻⁷m |
| 限界水深のFr−1 | 絶対1×10⁻⁷ |
| 等流水深のSfと参照勾配 | 絶対1×10⁻⁹または相対1×10⁻⁷ |

許容値はツール内に固定し、レポートにも記録します。結果に合わせて変更するCLIはありません。
これらは保存モデルの収支整合を調べる値で、現地水位の許容誤差を意味しません。

## 確認の範囲

これは収支の再算定です。別解法による水面形の予測、実河川の校正・誤差限界・設計認証は確認しません。
独立ODEや外部参照との[数値照査](validation.md)は引き続き別の証拠として保持します。
掘削土量・案間の差の要約・限界/等流根の一意性は、このツールでは検査しません。
CSV/HTMLはバイト列のハッシュを確認し、数値を再解析する対象は保存JSONです。
SHA-256は識別用で、原測量の認証・署名ではありません。マニフェストごと書き換えた出典を認証しません。
`baseline_profile_sha256`はRustのJSON表現で再エンコードせず、各保存基本プロファイルを値として直接比較します。
原CSV、利用条件、基準高、測量精度、ホストCI、人のレビューは別途確認が必要です。
Rustエンジンの全入力制約を再検証するものでもありません。断面幅比・河床急変等の
適用点検には[計算前診断](river-diagnostics.md)を使い、照査ツールの合格だけで適用範囲を広げません。

## 実行した検証

10件の合成テストで、解析的な矩形等流の常流/射流、台形/測量折れ線の積分、
地盤起伏と水面位置の乾いた峰による分離、ハッシュ改変・不正ZIP名、
ハッシュを書き直した流速/水深/限界・等流水深の改変、保存残差0のまま河床を改変した収支不一致、
条件不一致/未対応版/非有限JSON、失敗案の保持/架空の計算値の拒否、レポートの上書き防止を確認しました。
極端に大きい有限の堤岸高も合成ストレスケースに含め、クリップ割合の引算の桁落ちで
潤辺が欠落する不具合を修正しました。濡れた割合を直接算定し、元の成果でも再照査しています。

2026-10-12（JST）、同梱合成CSVの保存ZIPを照査しました。
施工・感度・測点間隔の7プロファイル、117計算点、110区間が合格。

元ZIPとプロジェクト/履歴は変更していません。記録は
`.local/review-pack-trial-20261012/offline-audit-verified.json`に保管しています。
