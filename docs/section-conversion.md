# 断面形式の切替

横断面エディタと施工案の断面置換では、形式を選ぶと変更前・変更候補を表示します。
「断面形式の変更を反映」で編集条件に反映し、取消では元の断面を保持します。
候補を表示したまま保存・計算しても、確認前の候補は使用しません。
エディタでは選択測点、またはチェックした全測点が対象です。河床標高や粗度は変更しません。
反映後のプロジェクト保存・計算履歴の追加は、それぞれ別の操作です。

| 切替 | 候補・制約 |
|---|---|
| 矩形 → 台形 | 幅・堤岸高を保持し、法勾配0で同じ垂直岸を表現 |
| 台形 → 矩形 | 底幅・堤岸高を保持し、法面を垂直に変更。形状変更を表示 |
| 台形 → 測量点 | 描画に使う元の4点をそのまま保持。xが厳密な昇順でない場合は拒否 |
| 矩形／法勾配0の台形 → 測量点 | 垂直岸の同一xを現エンジンの測量点形式で表現できないため拒否 |
| 測量点 → 矩形／台形 | 初期値（幅／底幅20m、堤岸高8m、台形の法勾配1.5）で新しい形状を作成。元の断面の近似ではないことを表示 |

測量点へ変換するために岸のx座標を移動したり、点を並べ替えたり、起伏を平滑化したりしません。
垂直岸は矩形・台形形式で保持できます。測量点形式を使う場合は、実際の形状を確認した
測量点CSVを明示的に取り込んでください。変換のために測量値を捏造しないでください。
最低点z=0、有限値、岸高、連続する1流路など、最終的な幾何・水理の検証はRustで実行します。

測量点入力欄の空の編集案は、元の点へ自動的に戻しません。反映操作でエラーを表示し、
最後に反映した形状を保持します。測点・プロジェクトが変わると、その入力案と切替候補を破棄します。
既存の計算履歴は変更しません。新しい解析は反映後に実行してください。

合成台形の全断面を測量点へ変換し、座標の完全一致と、同じRustエンジンでの水深・水位・
面積・流速・Froude数・等流水深・限界水深の差が1e-7未満であることをブラウザで検証します。
これは変換前後の整合性確認であり、独立した計算精度の検証や実河川の検証の代わりにはしません。
